::L1_05_Q1:: ما الفرق الأساسي بين عنوان IP والمنفذ (Port)؟ {
=IP يحدد الجهاز على الشبكة، والمنفذ يحدد الخدمة داخل ذلك الجهاز
~IP يحدد الخدمة، والمنفذ يحدد الجهاز
~كلاهما يؤديان نفس الوظيفة بالضبط
~المنفذ هو من يترجم اسم الموقع إلى IP
}

::L1_05_Q2:: ما الذي يفعله أمر <code>ping</code> تحديداً؟ {
=يرسل رسائل فحص قصيرة ليعرف هل الجهاز الهدف يستجيب، ويقيس زمن الرحلة
~يعرض كل الاتصالات المفتوحة على جهازك حالياً
~يترجم اسم الموقع إلى عنوان IP
~يلتقط حزم الشبكة ويحلل محتواها
}

::L1_05_Q3:: في مخرجات <code>traceroute</code>، ماذا يمثّل كل سطر مرقّم قبل السطر الأخير؟ {
=راوتراً (قفزة) مرّت به الحزمة في طريقها إلى الهدف
~خطأ في الاتصال يجب تجاهله
~نسخة مكررة من نفس الحزمة الأولى
~جهاز المستخدم نفسه مكرراً
}

::L1_05_Q5:: منفذ ظهر في نتيجة الفحص بحالة «مُرشَّح» (Filtered). ما معنى ذلك؟ {
=لم يصل أي رد من المنفذ، غالباً بسبب جدار حماية يمنع الاستجابة
~المنفذ مفتوح ويعمل بشكل طبيعي
~المنفذ مغلق تماماً وهذا مؤكد بالكامل
~المنفذ يستخدم بروتوكولاً مشفّراً فقط
}

::L1_05_Q6:: لماذا يُعدّ منفذ Telnet (23) المفتوح خطراً أمنياً؟ {
=لأنه يرسل اسم المستخدم وكلمة المرور نصاً واضحاً بلا تشفير
~لأنه لا يسمح بأي اتصال عن بُعد أصلاً
~لأنه مخصص فقط لنقل الملفات الكبيرة
~لأنه يستهلك سرعة الشبكة بشكل كبير
}

::L1_05_Q7:: في <code>netstat -an</code> ظهر اتصال ESTABLISHED إلى عنوان غريب على منفذ 4444 بينما الجهاز يعمل بشكل طبيعي ظاهرياً. ما أفضل تصرف؟ {
=التحقق من العملية المسؤولة عن الاتصال وإبلاغ المسؤول فوراً
~تجاهله لأن الجهاز يعمل بشكل طبيعي ظاهرياً
~إعادة تشغيل الجهاز فقط دون أي فحص آخر
~إيقاف تشغيل netstat لإخفاء التنبيه
}

::L1_05_Q8:: كتابة <code>dns</code> في شريط فلتر العرض (Display Filter) في Wireshark، ماذا تفعل؟ {
=تعرض فقط حزم أسئلة DNS وأجوبتها من بين كل الحزم الملتقطة
~تحذف كل الحزم غير الخاصة بـ DNS من الالتقاط نهائياً
~تلتقط حزم DNS جديدة من الشبكة فوراً
~تعرض فقط حزم HTTPS المشفّرة
}

::L1_05_Q9:: في التقاط حزم لموقع يعمل بـ HTTP (بدون تشفير)، ظهرت كلمة مرور المستخدم مقروءة بوضوح داخل طلب POST. ما السبب؟ {
=لأن HTTP يرسل محتوى الطلب كنص واضح بلا تشفير
~لأن المستخدم اختار كلمة مرور قصيرة جداً
~لأن Wireshark يفكّ أي تشفير تلقائياً بمجرد الالتقاط
~لأن الخادم كان يستخدم بروتوكول FTP بدل HTTP
}

::L1_05_Q10:: أنت في مقهى يقدّم شبكة Wi-Fi مفتوحة لأي زائر. هل يجوز لك تشغيل Wireshark والتقاط حزم بقية المستخدمين على هذه الشبكة؟ {

~نعم، لأن الشبكة مفتوحة لأي شخص فهي ملك عام

~نعم إذا كان الهدف هو التدريب والتعلم فقط
