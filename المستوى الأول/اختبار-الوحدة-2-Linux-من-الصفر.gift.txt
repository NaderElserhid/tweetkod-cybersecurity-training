::L1_02_Q1:: ماذا يفعل الأمر <code>pwd</code>؟ {
=يعرض المسار الكامل للمجلد الذي تقف فيه حالياً
~يعرض محتويات المجلد الحالي
~ينقلك إلى المجلد الرئيسي
~يعرض صلاحيات الملفات
}

::L1_02_Q2:: أي أمر يعرض الملفات المخفية (التي تبدأ أسماؤها بنقطة) داخل مجلد؟ {
=ls -a
~ls -h
~cat -a
~pwd -a
}

::L1_02_Q3:: ما وظيفة الأمر <code>cat</code>؟ {
=قراءة محتوى ملف نصي وطباعته على الشاشة
~إنشاء مجلد جديد
~تغيير صلاحيات ملف
~البحث داخل محتوى ملف
}

::L1_02_Q4:: أين توجد سجلات دخول الخادم (Logs) عادة في Linux؟ {
=/var/log
~/bin
~/root
~/home
}

::L1_02_Q5:: ماذا يُظهر الأمر <code>grep Failed auth.log</code>؟ {
=فقط الأسطر التي تحتوي كلمة Failed داخل الملف
~الملف كاملاً مع تمييز كلمة Failed
~عدد مرات ظهور Failed فقط كرقم
~يحذف كل الأسطر التي فيها Failed
}

::L1_02_Q6:: ما وظيفة الرمز <code>|</code> (الأنبوب) بين أمرين؟ {
=يمرّر ناتج الأمر الأول ليكون مدخلاً للأمر الثاني
~يحذف ناتج الأمر الأول قبل تنفيذ الثاني
~يشغّل الأمرين في الوقت نفسه دون علاقة بينهما
~يحفظ ناتج الأمر الأول في ملف تلقائياً
}

::L1_02_Q7:: في صلاحيات <code>-rwxr-xr-x</code>، ماذا يملك صاحب الملف (المالك)؟ {
=القراءة والكتابة والتنفيذ
~القراءة والتنفيذ فقط دون كتابة
~الكتابة فقط
~لا صلاحيات له على ملفه
}

::L1_02_Q8:: لماذا يفحص محلل الأمن مجلد <code>/tmp</code> غالباً أثناء التحقيق؟ {
=لأنه مفتوح للكتابة من كل المستخدمين فيحبّه المهاجمون لإخفاء أدواتهم
~لأنه محمي بالكامل ولا يصل إليه أحد
~لأنه يحتوي سجلات النظام فقط
~لأنه المجلد الوحيد القابل للتنفيذ
}

::L1_02_Q9:: وجدت ملفاً تنفيذياً مجهول المصدر بصلاحية x في النظام. ما التصرف الآمن؟ {
=أقرأه بـ cat دون تشغيله، ثم أوثّقه وأبلغ المسؤول
~أشغّله فوراً لأرى ماذا يفعل
~أتجاهله لأنه غالباً غير مهم
~أحذفه مباشرة دون توثيق
}

::L1_02_Q10:: ما الفرق الجوهري بين الأمرين <code>cp</code> و<code>mv</code>؟ {
=cp ينسخ ويُبقي الملف الأصلي، بينما mv ينقل الملف فيختفي من مكانه الأول
~لا فرق؛ الأمران متطابقان تماماً
~cp يحذف الملف الأصلي بعد النسخ
~mv يعمل فقط مع المجلدات لا الملفات
}
