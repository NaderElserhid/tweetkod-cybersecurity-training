::L1_04_Q1:: لماذا يُعدّ استخدام عوامل مثل <code>site\:</code> و<code>filetype\:</code> في Google «Dorking» ولا يُعدّ اختراقاً؟ {
=لأنه يعتمد على عوامل بحث رسمية موثّقة دون دخول إلى أي نظام
~لأنه يتيح الدخول لحسابات محمية بلا كلمة مرور
~لأنه أسلوب سري غير معروف لمحركات البحث
~لأنه يتجاوز إعدادات خصوصية المواقع
}

::L1_04_Q2:: ماذا يفعل الاستعلام <code>site\:school.edu filetype\:pdf</code>؟ {
=يعرض ملفات PDF فقط داخل موقع school.edu
~يعرض كل صفحات الإنترنت التي تذكر school.edu
~يعرض كل الملفات من أي نوع داخل school.edu
~يستبعد موقع school.edu من النتائج
}

::L1_04_Q3:: ما الفرق بين حقل <code>Date/Time Original</code> وحقل <code>File Modification Date</code> في مخرجات exiftool؟ {
=الأول وقت التصوير الحقيقي، والثاني وقت حفظ الملف على الجهاز
~لا فرق، كلاهما يعني نفس الشيء
~الأول يخص الجهاز والثاني يخص المصوّر
~الأول وقت الحفظ والثاني وقت التصوير
}

::L1_04_Q4:: إذا أظهر WHOIS أن اسم صاحب النطاق <code>REDACTED FOR PRIVACY</code>، ماذا يعني هذا؟ {
=استخدام خدمة خصوصية شائعة وقانونية، وليس دليلاً مؤكداً على الاحتيال
~دليل مؤكد على أن النطاق احتيالي
~النطاق غير مسجَّل رسمياً
~لا يمكن لأي أداة الوصول لمعلومات هذا النطاق
}

::L1_04_Q5:: وصلتك رسالة SMS تدّعي ربح جائزة، ونطاق الرابط فيها أُنشئ قبل يوم واحد فقط من وصول الرسالة. ماذا يدل هذا؟ {
=مؤشر قوي على حملة احتيال
~دليل على أن الموقع جديد وموثوق
~لا علاقة بين تاريخ النطاق ومصداقية الرسالة
~يعني أن الرسالة من جهة رسمية حديثة
}

::L1_04_Q6:: ظهر بريدك الإلكتروني في تسريب على Have I Been Pwned. ما الحل الصحيح؟ {
=تغيير كلمة المرور في كل حساب استُخدمت فيه، وتفعيل المصادقة الثنائية
~حذف البريد الإلكتروني نفسه فوراً
~الانتظار دون أي إجراء لأنه أمر شائع
~إرسال كلمة المرور للموقع لتأكيد الهوية
}

::L1_04_Q7:: في تدريب OSINT بهذه الوحدة، عن من يحقّ لك البحث؟ {
=عن نفسك فقط، أو بيانات خيالية ومؤسسية علنية
~عن زملائي ومعلّمي دون الحاجة لإذنهم
~عن أي شخص بشرط عدم إخباره بالنتيجة
~عن أي حساب تواصل اجتماعي عام أعثر عليه
}

::L1_04_Q8:: ما وظيفة أداة WhatsMyName؟ {
=التحقق إن وُجد حساب بنفس اسم المستخدم في مئات المنصات دفعة واحدة
~اختراق كلمات مرور الحسابات للتحقق من ملكيتها
~حذف الحسابات القديمة غير المستخدمة تلقائياً
~كشف كلمة مرور صاحب اسم المستخدم
}

::L1_04_Q9:: ما وظيفة أرشيف الإنترنت Wayback Machine (web.archive.org)؟ {
=الاحتفاظ بنسخ تاريخية من صفحات الويب، حتى لو حُذف المحتوى الأصلي
~حذف الصفحات القديمة من الإنترنت نهائياً
~فحص كلمات المرور المسرّبة لبريد معيّن
~تسجيل نطاقات جديدة للمواقع
}

::L1_04_Q10:: ما الفرق بين WHOIS وأداة DNSDumpster؟ {
=WHOIS يكشف من سجّل النطاق، وDNSDumpster يكشف كيف يُستضاف تقنياً ونطاقاته الفرعية
~DNSDumpster يكشف اسم المالك الحقيقي بدل WHOIS
~كلاهما يفعل نفس الشيء بالضبط
~WHOIS يحتاج اختراقاً وDNSDumpster لا يحتاج
}
