::L1_08_Q1:: ماذا يعني القفل الأخضر 🔒 بجانب رابط الموقع؟ {
=أن الاتصال بين متصفحك والموقع مشفّر فقط
~أن صاحب الموقع شخص موثوق تماماً
~أن الموقع خالٍ من أي برمجية خبيثة بالكامل
~أن البضاعة المعروضة في الموقع أصلية ومضمونة
}

::L1_08_Q2:: ما وظيفة خانة Subject Alternative Name (SAN) في شهادة الموقع؟ {
=تحدد قائمة النطاقات التي يحق لهذه الشهادة تغطيتها
~تحدد تاريخ انتهاء صلاحية الشهادة فقط
~تحدد اسم الجهة المصدِّقة التي وقّعت الشهادة
~تحدد عنوان IP الخاص بخادم الموقع
}

::L1_08_Q3:: موقع أُنشئ نطاقه قبل 6 أيام فقط ويعرض خصماً بنسبة 90%. ما التصرف الأصح؟ {
=التوقف والتحقق من النطاق والعمر قبل أي شراء
~الشراء فوراً لأن العرض مربح جداً ولن يتكرر
~تجاهل عمر النطاق لأنه غير مهم في التقييم
~طلب من صديق الشراء أولاً ليجرّب الموقع بدلاً عني
}

::L1_08_Q4:: في الرابط <code>https\://paypal.com.login-check.example/home</code>، ما النطاق الحقيقي الذي يملكه صاحب الموقع؟ {
=login-check.example
~paypal.com
~home.example
~paypal.com.login-check.example بالكامل كنطاق واحد
}

::L1_08_Q5:: ما الفرق الأساسي بين هجوم Pharming وهجوم Typosquatting؟ {
=في Pharming يكون الرابط المكتوب صحيحاً تماماً بينما DNS يحوّله لخادم مزيّف، أما Typosquatting يعتمد على خطأ إملائي في الرابط نفسه
~كلاهما يعتمدان على نفس الخطأ الإملائي في الرابط بالضبط
~Pharming يحدث فقط على الهاتف وTyposquatting فقط على الحاسوب
~لا فرق بينهما، وهما اسمان لنفس الهجوم تماماً
}

::L1_08_Q6:: ما وظيفة علامة HttpOnly على كوكي الجلسة؟ {
=تمنع سكربتات الصفحة (JavaScript) من قراءة الكوكي
~تمنع إرسال الكوكي عبر اتصال HTTPS المشفّر
~تجعل الكوكي يُحذف تلقائياً بعد كل دقيقة
~تسمح لأي موقع آخر بقراءة الكوكي بسهولة
}

::L1_08_Q7:: عدّلت نصاً في تبويب Elements بأداة Inspect في متصفحك. ماذا يحدث لهذا التعديل؟ {
=يبقى ظاهراً على جهازك فقط، ويختفي فور تحديث الصفحة لأن الخادم لم يتغيّر
~يظهر لكل زوار الموقع الآخرين فوراً
~يُحفظ بشكل دائم على خادم الموقع
~يغيّر قاعدة بيانات الموقع الحقيقية بعد إعادة التحميل
}

::L1_08_Q8:: فتحت موقعاً تملك فيه حساباً حقيقياً، لكن مدير كلمات المرور لم يقترح تعبئة بياناتك تلقائياً. ما أفضل تفسير وتصرف؟ {
=قد يكون النطاق مختلفاً عن المحفوظ، فيجب التوقف والتحقق من الرابط قبل كتابة أي شيء
~خلل تقني بسيط في المتصفح، فأكتب بياناتي يدوياً مباشرة
~يجب حذف مدير كلمات المرور لأنه لا يعمل بشكل صحيح
~هذا يعني أن الموقع حذف حسابي بالكامل
}

::L1_08_Q9:: إضافة متصفح بسيطة لتغيير الألوان تطلب صلاحية «قراءة وتغيير كل بياناتك في كل المواقع». كيف تقيّم هذا الطلب؟ {
=علامة تحذير قوية\: وظيفة بسيطة لا تحتاج صلاحية ضخمة كهذه
~أمر طبيعي تماماً لأن كل الإضافات تحتاج هذه الصلاحية
~يجب قبوله لأن رفضه يعطّل المتصفح بالكامل
~لا علاقة للصلاحيات بأمان الإضافة إطلاقاً
}

::L1_08_Q10:: في تبويب Network ظهر نموذج تسجيل الدخول يُرسَل إلى رابط يبدأ بـ <code>http\://</code> لا <code>https\://</code>. ماذا يعني ذلك؟ {
=أن كلمة المرور وبيانات النموذج تسير عبر الشبكة بلا تشفير ويمكن قراءتها في الطريق
~أن البيانات مشفّرة بطريقة مختلفة عن HTTPS لكنها آمنة بنفس القدر
~أن المتصفح سيرفض إرسال النموذج تلقائياً في هذه الحالة
~أن الموقع يستخدم بروتوكولاً أحدث وأكثر أماناً من HTTPS
}
