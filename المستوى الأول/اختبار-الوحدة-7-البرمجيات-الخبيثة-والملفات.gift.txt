::L1_07_Q1:: ملف اسمه <code>photo.png</code> لكن أمر <code>file</code> أظهر عنه <code>PE32 executable (GUI)</code>. ما الذي يعنيه هذا؟ {
=أنه برنامج تنفيذي متنكّر بامتداد صورة
~أنه صورة تالفة لا يمكن فتحها
~أنه ملف مضغوط يحتاج برنامج فك ضغط
~أنه نوع صورة نادر يدعمه ويندوز فقط
}

::L1_07_Q2:: في اسم الملف <code>report.pdf.exe</code>، ما الامتداد الحقيقي للملف؟ {
=exe، لأنه الجزء الأخير بعد آخر نقطة
~pdf، لأنه يظهر أولاً في الاسم
~كلاهما معاً يُعتبران امتداداً واحداً
~لا يوجد امتداد حقيقي لهذا الملف
}

::L1_07_Q3:: ما أفضل طريقة لمعرفة إن كان ملف مشبوه معروفاً كخبيث، دون تشغيله أو رفعه لأي موقع؟ {
=حساب بصمته SHA-256 بأداة مثل sha256sum والبحث عنها في VirusTotal
~تشغيله في جهازك الشخصي ومراقبة ما يحدث بنفسك
~فتحه بمحرر نصوص عادي لقراءة كل محتواه حرفاً بحرف
~رفعه مباشرة إلى أي موقع تحليل عام دون التحقق من سياسته
}

::L1_07_Q4:: ماذا تفعل أداة <code>strings</code> عند تشغيلها على ملف تنفيذي مشبوه؟ {
=تستخرج النصوص المقروءة المخزَّنة داخل الملف مثل الروابط أو أسماء الأوامر
~تشغّل الملف في بيئة معزولة وتسجّل سلوكه خطوة بخطوة
~تحذف أي نص ضار تجده داخل الملف تلقائياً
~تحوّل الملف بالكامل إلى نص عربي مقروء
}

::L1_07_Q5:: إذا صنّف محرّك أمني واحد فقط من 70 على VirusTotal ملفاً بأنه خبيث، كيف تفسّر ذلك؟ {
=قد يكون إنذاراً كاذباً من محرك واحد، ويحتاج الأمر مراجعة المصدر والسلوك قبل أي حكم نهائي
~هذا دليل قاطع على خطورة الملف بنسبة مئة بالمئة
~يعني أن الملف نظيف تماماً ولا داعي لأي حذر إطلاقاً
~يعني أن تسعة وستين محركاً أكّدوا أن الملف آمن
}

::L1_07_Q6:: لماذا لا يُنصح برفع ملف واجبك أو مستند شخصي إلى VirusTotal للتأكد من سلامته؟ {
=لأن الملفات المرفوعة تُشارَك مع جهات أمنية متعددة وقد يطّلع عليها آخرون
~لأن الموقع يحذف الملفات المرفوعة فوراً دون فحصها
~لأن رفع الملفات يصيب جهازك ببرمجية خبيثة تلقائياً
~لأن الموقع لا يقبل سوى الملفات التنفيذية فقط
}

::L1_07_Q7:: ما أول خطوة صحيحة إذا ظهرت رسالة فدية على جهازك؟ {
=فصل الجهاز عن الشبكة (Wi-Fi والكابل) وإبلاغ الأهل أو مسؤول الأمن
~دفع الفدية فوراً لاستعادة الملفات بأسرع وقت ممكن
~الاستمرار في استخدام الجهاز بشكل طبيعي لأن الأمر سينتهي من نفسه
~إعادة تشغيل الجهاز عدة مرات متتالية فقط دون أي إجراء آخر
}

::L1_07_Q8:: ما الذي يجعل فلاشة BadUSB خطرة تحديداً؟ {
=تتنكّر إلكترونياً بأنها لوحة مفاتيح (HID) فيثق بها النظام تلقائياً دون فحص، وتكتب أوامر بسرعة كبيرة
~تنشر نفسها تلقائياً عبر الإنترنت إلى أجهزة أخرى بلا أي توصيل فعلي
~تحتوي على ملف يمكن فحصه مباشرة بأداة file مثل أي ملف آخر
~تتطلب من المستخدم تثبيت برنامج معيّن حتى تعمل
}

::L1_07_Q9:: ماذا تعني قاعدة النسخ الاحتياطي 3-2-1؟ {
=ثلاث نسخ من البيانات، على وسيطين مختلفين، واحدة منها خارج المكان أو غير متصلة بالجهاز
~ثلاث نسخ على القرص نفسه بأسماء مختلفة فقط
~نسخة واحدة تُحدَّث كل 321 يوماً بالتمام
~نسختان فقط متصلتان دائماً بالجهاز للوصول السريع
}

::L1_07_Q10:: ملف Word يطلب الضغط على <b>Enable Content</b> لعرض محتوى يبدو مهماً، وهو من مصدر مجهول. ما التصرف الآمن؟ {
=عدم تفعيله، لأنه قد يشغّل ماكرو (كوداً مخفياً) تلقائياً بمجرد الضغط
~تفعيله دائماً لأن ملفات Word آمنة بطبيعتها
~حذف الملف فوراً دون أي محاولة لفهم ما يطلبه أو توثيقه
~تفعيله فقط إذا كان حجم الملف صغيراً جداً
}
