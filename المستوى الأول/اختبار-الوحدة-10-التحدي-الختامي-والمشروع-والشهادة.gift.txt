::L1_10_Q1:: ما الأمر الذي يكشف الملفات المخفية (التي يبدأ اسمها بنقطة) في Linux؟ {
=ls -a
~ls -l
~cat -a
~grep -a
}

::L1_10_Q2:: في سجل الدخول، ما الذي يدل على هجوم تخمين كلمات مرور ناجح (Brute force)؟ {
=عشرات المحاولات الفاشلة من عنوان واحد يتبعها سطر Accepted من نفس العنوان
~سطر Accepted واحد بلا أي محاولة فاشلة قبله
~محاولة فاشلة واحدة من عنوان مختلف كل مرة
~سطر يسجل إعادة تشغيل الخادم
}

::L1_10_Q3:: الترميز مثل Hex أو Base64 يختلف عن التشفير الحقيقي لأنه\: {
=لا يحتاج مفتاحاً سرياً، وأي شخص يستطيع فكّه
~يستهلك وقتاً أطول لفكّه
~يعمل فقط على الأرقام
~يحتاج اتصالاً بالإنترنت لفكّه
}

::L1_10_Q4:: لماذا تُعدّ شيفرة قيصر (Caesar) ضعيفة ولا تحمي بيانات حقيقية؟ {
=لأن عدد الإزاحات الممكنة 25 فقط ويمكن تجربتها كلها بسرعة
~لأنها تعمل فقط على الحروف الكبيرة
~لأنها تحتاج اتصالاً بالإنترنت
~لأنها تغيّر طول النص الأصلي
}

::L1_10_Q5:: لماذا لا يمكن استخراج كلمة المرور الأصلية مباشرة من بصمتها (Hash) مثل SHA-256؟ {
=لأن الهاش دالة اتجاه واحد لا تُعكس رياضياً
~لأن البصمة مشفّرة بمفتاح سري
~لأن طول البصمة يتغير حسب كلمة المرور
~لأن البصمة تُحذف بعد الاستخدام
}

::L1_10_Q6:: ما المعلومات الحساسة التي قد تكشفها بيانات EXIF داخل صورة؟ {
=اسم صاحب الصورة والموقع الجغرافي ووقت التصوير
~حجم الصورة بالبكسل فقط
~لون الخلفية في الصورة
~عدد مرات مشاهدة الصورة
}

::L1_10_Q7:: ما أقوى علامة تدل أن ملفاً مرفقاً اسمه Invoice.pdf.exe خطير؟ {
=الامتداد الحقيقي الأخير exe يعني برنامجاً تنفيذياً لا ملف PDF
~اسمه يحتوي على كلمة Invoice
~حجمه كبير جداً
~أنه أُرسل في المساء
}

::L1_10_Q8:: لماذا يُعدّ بروتوكول FTP غير آمن لإرسال كلمات المرور؟ {
=يرسل اسم المستخدم وكلمة المرور نصاً عادياً بلا تشفير
~يحتاج اتصالاً بطيئاً جداً
~يعمل فقط على الشبكات اللاسلكية
~يرفض الاتصال من خارج المدرسة
}

::L1_10_Q9:: ما الخطأ في تصميم موقع يخزّن صلاحية المستخدم (مثل role\=admin) داخل كوكي يتحكم به المتصفح فقط؟ {
=يسمح لأي زائر بتعديل الكوكي ورفع صلاحياته دون أن يتحقق الخادم
~يجعل الموقع أبطأ في التحميل
~يمنع المستخدم من تسجيل الخروج
~يزيد حجم الكوكي فقط
}

::L1_10_Q10:: متصفحك يحذّر من شهادة TLS لأن subject وissuer فيها متطابقان تماماً. ما السبب؟ {
=الشهادة موقّعة ذاتياً (Self-signed) دون جهة خارجية موثوقة تشهد لها
~الشهادة منتهية الصلاحية
~اسم النطاق في الشهادة مختلف عن الموقع
~الاتصال غير مشفّر بالكامل
}
