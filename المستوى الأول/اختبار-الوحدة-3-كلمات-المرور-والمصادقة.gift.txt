::L1_03_Q1:: لماذا يخزّن الموقع هاش (Hash) كلمة المرور بدلاً من النص الصريح؟ {
=لأنه إن سُرقت قاعدة البيانات لن يستطيع المهاجم قراءة كلمة المرور مباشرة
~لأن الهاش يجعل الدخول أسرع للمستخدم
~لأن الهاش يشغل مساحة أقل من النص العادي فقط
~لأن المواقع القديمة لا تدعم تخزين النصوص
}

::L1_03_Q2:: ما الذي يحدث لناتج الهاش عند تغيير حرف واحد فقط في كلمة المرور؟ {
=يتغيّر الناتج بالكامل
~يتغيّر آخر رمزين منه فقط
~يبقى الناتج نفسه تماماً
~يصبح الناتج أقصر بحرف واحد
}

::L1_03_Q3:: هل استخدام نفس كلمة المرور في عدة حسابات آمن طالما كانت قوية ومعقدة؟ {
=لا، لأن تسريب موقع واحد يعرّض كل حساباتك الأخرى (Credential Stuffing)
~نعم، القوة والتعقيد يكفيان دائماً
~نعم، بشرط أن يكون طولها 20 حرفاً فأكثر
~لا يهم إن كانت الحسابات من نوع واحد فقط
}

::L1_03_Q4:: ما الأداة التي استُخدمت في مختبر اليوم لكسر هاشات ضعيفة بقائمة كلمات (Wordlist)؟ {
=John the Ripper
~nmap
~Wireshark
~exiftool
}

::L1_03_Q5:: هل يمكن عكس أي هاش رياضياً واستخراج كلمة المرور الأصلية منه مباشرة؟ {
=لا، دوال الهاش غير قابلة للعكس رياضياً، وتُكسر فقط بالتخمين
~نعم، بحاسوب قوي بما يكفي
~نعم، إن عرف المهاجم طول كلمة المرور
~نعم، باستخدام أداة فك تشفير عامة
}

::L1_03_Q6:: لماذا كُسرت كلمة مرور المستخدم admin بسرعة في مختبر اليوم؟ {
=لأنها كانت موجودة ضمن قائمة الكلمات (wordlist) المستخدمة
~لأن اسم المستخدم admin سهل التخمين دائماً
~لأن أداة john تكسر فقط حسابات المسؤولين
~لأن هاشها كان أقصر من الهاشات الأخرى
}

::L1_03_Q7:: من أي معطيات يُحسَب رمز التحقق (TOTP) في تطبيق المصادقة؟ {
=من سرّ مشترك بين جوالك والخادم مع الوقت الحالي
~من رقم هاتفك وعنوان IP الخادم
~من كلمة المرور نفسها مباشرة
~من اسم المستخدم فقط
}

::L1_03_Q8:: لماذا تُعدّ المفاتيح المرورية (Passkeys) أصعب سرقة بالتصيّد الاحتيالي من كلمة المرور التقليدية؟ {
=لأنها لا تُكتب ولا تُرسَل كنص أبداً، بل تبقى داخل الجهاز
~لأنها أطول من كلمة المرور العادية
~لأنها تتغيّر كل 30 ثانية مثل TOTP
~لأنها تُخزَّن مشفّرة في قاعدة بيانات الموقع
}

::L1_03_Q9:: ماذا يطلب موقع Have I Been Pwned منك لفحص تسريبات البيانات؟ {
=عنوان بريدك الإلكتروني فقط
~بريدك وكلمة مرورك معاً
~كلمة مرورك فقط للمقارنة
~رقم جوالك ورمز تحقق
}

::L1_03_Q10:: وصلك طلب تحقق (MFA) لتسجيل دخول لم تقم به. ما الإجراء الصحيح؟ {
=رفضه فوراً ثم تغيير كلمة المرور لأن شخصاً آخر يعرفها
~الموافقة لأنه قد يكون دخولاً نسيته
~تجاهله والاستمرار في عملك
~مشاركة رمز التحقق مع صديق للتأكد
}
