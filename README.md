# TweetKod — Cybersecurity Training Course
## دورة تويتكود التدريبية في الأمن السيبراني

دورة تدريبية عربية كاملة في الأمن السيبراني، مبنية كنظام شرائح HTML مخصّص بمختبرات تفاعلية حقيقية تعمل داخل المتصفح — بلا حاجة لتثبيت أي برنامج على جهاز الطالب.

---

## 📦 ماذا تضم الدورة؟

| | |
|---|---|
| **المستوى الأول** | 10 وحدات · 15 ساعة تدريبية — الأساسيات (Linux، كلمات المرور، الشبكات، OSINT، البرمجيات الخبيثة، أمن الويب، الجوال، وتحدٍّ ختامي) |
| **المستوى الثاني** | 12 وحدة · 18 ساعة تدريبية — مهارات متقدمة (Python، الاختراق الأخلاقي، التشفير، الطب الجنائي الرقمي، الاستجابة للحوادث، أمن الذكاء الاصطناعي، وCTF ختامي) |

كل وحدة = ملف HTML واحد مكتفٍ ذاتياً، يضم:

- شرائح تفاعلية برسوم SVG ورسوم متحركة أصلية
- طرفية Linux محاكاة تفاعلياً داخل الصفحة (أوامر حقيقية بنظام ملفات وهمي)
- تحديات بنقاط، وتحقّقات سريعة صح/خطأ بعد كل موضوع
- اختبار نهاية الوحدة (اختيار من متعدد) قابل للتصدير بصيغة **GIFT** للاستيراد المباشر في **Moodle**
- وضع ليلي/نهاري، وتحكم بحجم الخط، وفهرس شرائح جانبي

## 🛠️ البناء محلياً

يتطلب **Python 3** و**Node.js** (لتشغيل فاحص البنية `lint.js`).

```bash
cd _build-system

# بناء وحدة واحدة
python3 build.py L1 01      # الوحدة 1 من المستوى الأول
python3 build.py L2 05      # الوحدة 5 من المستوى الثاني

# بناء كل الوحدات (المستويين)
python3 build.py all
```

يفحص السكربت كل وحدة أولاً (حد أدنى من المختبرات، التحديات، التحقّقات السريعة، وبنية الاختبار)، ثم يولّد:
- ملف HTML كامل للوحدة داخل مجلد المستوى المناسب
- ملف اختبار بصيغة `.gift.txt` جاهز للاستيراد في Moodle (Question bank → Import → GIFT format)

لإضافة أو تعديل وحدة، راجع `_build-system/AUTHORING.md` أولاً — فيه كل قواعد الكتابة والمكوّنات المتاحة.
