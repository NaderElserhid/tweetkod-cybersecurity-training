::L2_03_Q1:: ما الترتيب الصحيح لمراحل اختبار الاختراق الأخلاقي في هذه الوحدة؟ {
=استطلاع ← فحص ← تعداد ← تقرير وتصحيح
~استغلال ← استطلاع ← فحص ← تقرير
~فحص ← استطلاع ← تقرير ← تعداد
~تعداد ← فحص ← استطلاع ← استغلال
}

::L2_03_Q2:: ما الفرق الأساسي بين الاستطلاع السلبي والنشط؟ {
=السلبي لا يرسل أي حزمة مباشرة للهدف، والنشط يرسل حزماً فعلية قد تظهر في سجلاته
~السلبي أسرع من النشط لكنه أقل دقة
~السلبي يحتاج إذناً كتابياً والنشط لا يحتاجه
~النشط يستخدم فقط أدوات مجانية مثل Shodan
}

::L2_03_Q3:: ما الترتيب الصحيح لخطوات المصافحة الثلاثية TCP؟ {
=SYN ثم SYN/ACK ثم ACK
~ACK ثم SYN ثم SYN/ACK
~SYN/ACK ثم SYN ثم ACK
~SYN ثم ACK ثم SYN/ACK
}

::L2_03_Q4:: لماذا يُسمّى فحص SYN في Nmap "نصف مفتوح" (Half-open)؟ {
=لأنه لا يكمل المصافحة الثلاثية أبداً، بل يرسل RST بدل ACK
~لأنه يفحص نصف المنافذ المطلوبة فقط ثم يتوقف
~لأنه يحتاج نصف الوقت الذي يحتاجه الفحص العادي
~لأنه يعمل فقط على نصف نطاق الشبكة المحدد
}

::L2_03_Q5:: ماذا تعني حالة المنفذ closed في مخرجات Nmap؟ {
=الجهاز حيّ ويردّ على الفحص، لكن لا تطبيق يستمع على هذا المنفذ
~الجهاز مطفأ أو غير موجود على الشبكة
~جدار حماية يحجب الوصول إلى المنفذ تماماً
~المنفذ مفتوح لكنه محمي بكلمة مرور
}

::L2_03_Q6:: ما وظيفة خيار <code>-p-</code> في Nmap؟ {
=فحص كل المنافذ الـ 65535 بدل أشهر 1000 منفذ فقط
~إيقاف المسح فور بدئه لتوفير الوقت
~تحديد اسم الخدمة ونسختها على كل منفذ
~فحص المنافذ المفتوحة حصراً دون المغلقة
}

::L2_03_Q7:: ما سياسة الاستخدام المعلنة لخادم scanme.nmap.org؟ {
=الالتزام بنحو 12 عملية مسح يومياً فقط، وعدم استخدامه لتخمين كلمات المرور
~لا قيود على عدد مرات الفحص لأنه خادم تجريبي مخصص لذلك
~يُمنع فحصه إلا بإذن كتابي مسبق من فريق Nmap
~يسمح فقط بفحص المنفذ 80 ولا شيء غيره
}

::L2_03_Q8:: ماذا يكشف موقع crt.sh؟ {
=سجلات Certificate Transparency العلنية التي قد تكشف نطاقات فرعية لنطاق معين
~كلمات مرور مستخدمين مسرَّبة من خوادم الشهادات
~المنافذ المفتوحة على خادم معين مباشرة
~محتوى الرسائل المتبادلة بين الخادم والعميل
}

::L2_03_Q9:: ما العناصر الأربعة التي يجب أن يتضمنها تقرير استطلاع جيد في هذه الوحدة؟ {
=الملاحظة والدليل والخطورة والتوصية (Finding, Evidence, Risk, Fix)
~الهدف والأداة والنتيجة والتوقيع
~اسم الفاحص وتاريخ الفحص وعنوان IP ونوع النظام
~المنفذ المفتوح وكلمة المرور المكتشفة وخطة الاستغلال
}

::L2_03_Q10:: ما الذي يحدده خيار <code>-sV</code> في Nmap؟ {
=يحاول تحديد اسم الخدمة ونسختها على كل منفذ مفتوح وجده
~يكتشف الأجهزة الحيّة في الشبكة فقط دون فحص منافذها
~يمنع الجهاز الهدف من اكتشاف عملية الفحص
~يحذف المنافذ المغلقة من قائمة النتائج النهائية
}
