::L2_01_Q3:: في فاحص المنافذ بمكتبة socket، ماذا تعني النتيجة 0 التي تعيدها connect_ex؟ {
=الاتصال نجح، أي أن المنفذ مفتوح (OPEN)
~المنفذ مغلق تماماً
~حدث خطأ في الشبكة
~الجهاز غير متصل بالإنترنت
}

::L2_01_Q4:: لماذا يجب أن يبقى TARGET في سكربت فحص المنافذ التعليمي يساوي 127.0.0.1؟ {
=لأن فحص جهاز آخر لا تملكه أو لا تملك إذناً صريحاً لفحصه غير قانوني وغير أخلاقي
~لأن 127.0.0.1 هو العنوان الوحيد الذي تدعمه مكتبة socket
~لأن تغييره يعطّل السكربت فوراً
~لأن أي عنوان آخر يحتاج اتصالاً بالإنترنت فقط
}

::L2_01_Q5:: ما وظيفة مكتبة re (التعبيرات النمطية) في سكربت محلل السجلات؟ {
=البحث عن نمط نصي متكرر الشكل مثل عنوان IP داخل سطر السجل
~حساب بصمة الهاش للنص
~فتح اتصال شبكي بمنفذ معيّن
~ترتيب الأرقام تصاعدياً
}

::L2_01_Q6:: ماذا تفعل الدالة counter.most_common() في سكربت محلل السجلات؟ {
=ترتّب عناوين IP تنازلياً حسب عدد مرات تكرارها
~ترتّب العناوين أبجدياً
~تحذف العناوين المتكررة أقل من مرتين
~تحوّل كل عنوان إلى بصمة هاش
}

::L2_01_Q7:: لماذا لا يمكن استخدام hashlib.sha256() لاستعادة كلمة المرور الأصلية من بصمتها؟ {
=لأن SHA-256 دالة اتجاه واحد لا تُعكس رياضياً إلى النص الأصلي
~لأن بايثون يحذف النص الأصلي من الذاكرة فوراً
~لأن الدالة تحتاج مفتاحاً سرياً غير متوفر
~لأن طول البصمة يتغيّر مع كل تشغيل للسكربت
}

::L2_01_Q8:: ما الفرق الجوهري بين التشفير مثل Caesar وXOR والترميز مثل Base64؟ {
=التشفير يحتاج مفتاحاً أو سرّاً لفكّه، بينما الترميز لا يحتاج أي سرّ ويمكن فكّه فوراً
~التشفير أبطأ من الترميز فقط
~الترميز يعمل على الأرقام فقط
~لا فرق حقيقي بينهما
}

::L2_01_Q9:: عند تطبيق xor_crypt مرتين على نفس البيانات بنفس المفتاح، ما النتيجة؟ {
=تعود البيانات إلى شكلها الأصلي كما كانت قبل التشفير
~تُحذف البيانات نهائياً
~يتضاعف طول البيانات
~تتحوّل البيانات إلى نص Base64
}
