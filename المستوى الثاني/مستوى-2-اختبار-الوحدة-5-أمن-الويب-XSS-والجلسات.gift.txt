::L2_05_Q1:: ما السؤال الذي يحدد نوع XSS (منعكس/مخزَّن/DOM) بحسب هذه الوحدة؟ {
=أين ينتهي نص المهاجم\: في الرد الفوري، في قاعدة البيانات، أم داخل جافاسكربت المتصفح؟
~كم عدد الأحرف التي كتبها المهاجم في النص
~أي متصفح يستخدمه الضحية عند فتح الصفحة
~هل الموقع يستخدم HTTPS أم HTTP فقط
}

::L2_05_Q2:: ما الفرق بين XSS المنعكس (Reflected) والمخزَّن (Stored)؟ {
=المنعكس يظهر فقط في الرد الفوري لنفس الطلب، والمخزَّن يُحفظ في قاعدة البيانات ويظهر لكل زائر لاحق
~المنعكس أخطر من المخزَّن في جميع الحالات
~المخزَّن يحدث فقط داخل جافاسكربت المتصفح دون خادم
~المنعكس يحتاج تسجيل دخول الضحية والمخزَّن لا يحتاجه
}

::L2_05_Q3:: ما وظيفة ترميز المخرجات (Output Encoding)؟ {
=تحويل الرموز الخاصة مثل < و> إلى صيغة نصية آمنة قبل عرضها، فتُعرض كنص فقط لا تُنفَّذ
~حذف أي رمز خاص من النص قبل تخزينه نهائياً
~تشفير النص بالكامل بمفتاح سري قبل عرضه
~منع المستخدم من كتابة أي رمز خاص أصلاً
}

::L2_05_Q4:: ما دور علامة HttpOnly على كوكي الجلسة؟ {
=تمنع قراءة الكوكي بجافاسكربت داخل المتصفح
~تمنع الخادم نفسه من قراءة قيمة الكوكي
~تشفّر قيمة الكوكي تلقائياً أثناء الإرسال
~تمنع إرسال الكوكي عبر أي اتصال غير مشفّر
}

::L2_05_Q5:: ماذا يكشف أمر curl -I عن رد خادم ويب؟ {
=ترويسات HTTP فقط (Headers)، دون تحميل محتوى الصفحة كاملاً
~محتوى الصفحة الكامل كما يظهر في المتصفح تماماً
~قائمة بكل كوكيز الموقع المخزّنة في المتصفح
~كلمة مرور المستخدم المسجّل دخوله حالياً
}

::L2_05_Q6:: كيف يختلف CSRF عن XSS؟ {
=CSRF لا يُدرج كوداً في صفحة الضحية، بل يستغل إرسال المتصفح للكوكي تلقائياً مع طلب لنطاق موثوق
~CSRF يحتاج دائماً إدراج كود جافاسكربت في صفحة الضحية تماماً كـXSS
~CSRF يحدث فقط عندما يكون الضحية غير مسجّل دخوله في أي موقع
~CSRF يتطلب سرقة كلمة مرور الضحية أولاً
}

::L2_05_Q7:: ما دور ترويسة Content-Security-Policy (CSP)؟ {
=تحدّد للمتصفح مصادر الأكواد والمحتوى المسموح تحميلها، فتحدّ من تنفيذ كود غير مصرّح به حتى لو نجح إدراجه
~تشفّر كل حركة التصفح بين المتصفح والخادم تلقائياً
~تمنع المستخدم من فتح أكثر من تبويب للموقع نفسه
~تحذف الكوكيز القديمة من المتصفح تلقائياً
}

::L2_05_Q8:: متى تحتاج مكتبة مثل DOMPurify بشكل خاص؟ {
=حين يحتاج الموقع فعلياً لعرض HTML كتبه المستخدم (مثل محرر تنسيق)، فتزيل الوسوم والسمات الخطرة وتُبقي المسموح فقط
~فقط عند استخدام قاعدة بيانات SQL تقليدية
~بدلاً من ترميز المخرجات في كل الحالات بلا استثناء
~فقط على المواقع التي لا تستخدم HTTPS
}

::L2_05_Q9:: لماذا تساعد خاصية SameSite على الكوكي في تقليل خطر CSRF؟ {
=لأنها تحدّ من إرفاق الكوكي تلقائياً مع طلبات قادمة من مواقع أخرى
~لأنها تشفّر محتوى الكوكي بالكامل
~لأنها تمنع جافاسكربت الصفحة نفسها من قراءة الكوكي
~لأنها تحذف الكوكي فوراً بعد كل طلب HTTP
}

::L2_05_Q10:: ما التصرف الصحيح عند اكتشاف ثغرة XSS في موقع حقيقي يملك برنامج مكافآت أمنية؟ {
=الإبلاغ عبر قناة الإفصاح الرسمية بوصف دقيق للملاحظة دون أي استغلال إضافي
~تجربة إدخال نصوص أكثر على الموقع نفسه للتأكد من خطورة الثغرة
~الانتظار حتى تجد ثغرة أخطر قبل الإبلاغ عن أي شيء
~طلب مبلغ مالي إضافي مقابل عدم نشر التفاصيل علناً
}
