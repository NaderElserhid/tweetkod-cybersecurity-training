::L2_02_Q3:: ما وظيفة طبقة الإنترنت (Internet) في نموذج TCP/IP؟ {
=عنونة الأجهزة بعناوين IP وتوجيه البيانات بين الشبكات
~تقسيم البيانات وترقيمها بالمنافذ
~عرض الصفحات على المستخدم مباشرة
~ربط عنوان IP بعنوان MAC فقط
}

::L2_02_Q4:: ماذا يعرض فلتر Wireshark tcp.flags.syn \=\= 1 && tcp.flags.ack \=\= 0؟ {
=أول حزمة SYN في بداية كل اتصال TCP جديد
~حزمة ACK الأخيرة في نهاية المصافحة
~كل حزم HTTP فقط
~الحزم المشفّرة فقط
}

::L2_02_Q5:: جدول ARP لديك تغيّر فجأة وصار عنوان الراوتر يشير إلى جهاز مختلف. ماذا يدل هذا غالباً؟ {
=مؤشر شائع على هجوم ARP Spoofing واعتراض محتمل لحركتك
~تحديث تلقائي طبيعي للراوتر لا يستدعي القلق
~خلل في سرعة الإنترنت فقط
~تغيير عادي يحدث بلا أي سبب يُذكر
}

::L2_02_Q6:: ما الذي يحمي محتوى بياناتك من القراءة حتى لو نجح شخص باعتراض اتصالك على الشبكة المحلية؟ {
=استخدام HTTPS الذي يشفّر المحتوى من طرف لطرف
~الاتصال بشبكة Wi-Fi ذات اسم مألوف فقط
~سرعة الإنترنت المرتفعة
~استخدام متصفح مختلف
}

::L2_02_Q7:: ما وظيفة ميزة Dynamic ARP Inspection (DAI) على سويتش مُدار؟ {
=مراقبة رسائل ARP وإسقاط أي رسالة لا تطابق سجل DHCP الموثوق
~تسريع نقل البيانات بين المنافذ
~تشفير كل حركة الشبكة تلقائياً
~حجب الإنترنت عن أجهزة معيّنة
}

::L2_02_Q8:: ما الذي يميّز WPA3 عن WPA2 في مقاومة تخمين كلمة مرور Wi-Fi؟ {
=WPA3 يستخدم آلية SAE تقاوم تخمين كلمة المرور بلا اتصال حتى لو التُقطت المصافحة
~WPA3 يستخدم نفس آلية WPA2 بلا أي تغيير
~WPA2 أقوى من WPA3 في كل الحالات
~WPA3 لا يحتاج كلمة مرور على الإطلاق
}

::L2_02_Q9:: هل يجعل تفعيل VPN المستخدم مجهول الهوية تماماً على الإنترنت؟ {
=لا، لأن خادم VPN نفسه يرى حركة المستخدم ولا يضمن إخفاء هويته تماماً
~نعم، يصبح تتبعه مستحيلاً تماماً
~نعم، لأن VPN يحذف كل بياناته فوراً
~لا علاقة لـVPN بإخفاء الهوية أساساً
}

::L2_02_Q10:: في شبكة Wi-Fi عامة غير مؤكدة الهوية بالكامل (كمقهى)، متى يُفضَّل تفعيل VPN؟ {
=قبل تصفح أي حساب حساس على الشبكة لا بعده
~بعد الدخول إلى الحسابات الحساسة فقط
~فقط عند رؤية قفل HTTPS في المتصفح
~لا حاجة له إطلاقاً في المقهى
}
