::L2_12_Q2:: لماذا يُفضَّل تتبّع كود Python يدوياً بدل تشغيله مباشرة عند مراجعة شيفرة مجهولة المصدر؟ {

::L2_12_Q3:: ما الذي يجعل مفتاح XOR بايت واحد متكرر ضعيفاً جداً أمام هجوم النص المعروف؟ {

~لأن XOR لا يمكن حسابه إلا بأجهزة متخصصة غالية الثمن

}

~لأن البصمة بلا ملح تكون أقصر من البصمة بملح دائماً

~لأن البصمة بلا ملح يمكن عكسها رياضياً مباشرة
}

::L2_12_Q8:: ما الفرق الأساسي بين خاصيتي HttpOnly وSecure في الكوكيز؟ {
=HttpOnly تمنع قراءة الكوكي عبر جافاسكربت، وSecure تمنع إرساله إلا عبر HTTPS مشفّر
~كلتاهما تمنعان قراءة الكوكي عبر جافاسكربت بالطريقة نفسها
~HttpOnly تشفّر قيمة الكوكي، وSecure تضغطها لتوفير مساحة
~كلتاهما تحذفان الكوكي تلقائياً بعد انتهاء الجلسة
}
